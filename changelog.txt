General Package: 
- Added Bundle for Modloader
-- Pack will now be identified as nested by mod-loader
-- To Disable a specific package: Rename Package with an "-" infromt of the Folder Name. E.g. "-Dolphin-Pack"
- Known-Issue?: (technical stuff)
-- When Bundling the pack all Icon Refs are lost. And only when bundled.
-- Reason is that for some magical reason all submods start using the parent mod as path reference.
-- This caused all icons to disappear.
-- Workaround is an Additional Folder containing all Icons with the same data structure from each submod
-- Bundle is sadly required to be identified by Community Modloader
-- Disadvantage: Now each Icon is saved 2 times.
-- And yes I tried already adding "*/", "<sub-mod-name>/, and every different variant in front of the IconFilename -- still dont work.
-- Also when bundled the load order is relevant...
-- the parent mod needs to be loaded >last<. Otherwise Icons are again broken...
-- its so annoying... >.<

-- If you want this pack to be compatible with mod manager you need to keep the modinfo.json & data\... folder.
-- the game mod loader does not care.
-- If you rip the submods out you can ignore the modinfo.json & the data-folder from the main directory.

--- TLDR:
--- You use mod manager? Keep everything as is and only update main-package
